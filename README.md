# 科研工程同行

给 Codex 的一个 skill，陪你推敲科研想法、解决工程问题，把想法推进到能证明、能实验或者能落地的程度。

做科研时，它会从问题的结构和现有结果出发，尝试构造让想法成立的条件。遇到反例或实验不符合预期，就找出失效的位置，调整假设、方法或数据设计，保留仍然有价值的结果，继续往前推。

做工程时，它会先检查代码、输入和实际现象，分析瓶颈或故障机制，再修改实现并运行合适的验证。涉及 LLM systems 或数学优化时，也会按问题估算计算、访存、通信、求解规模等成本。

它还会让 Codex 把话说清楚：直接讲结论、原因和依据，少写套话、空泛免责声明和操作流水账。该推导就展开推导，该执行就动手；提出的想法和已经得到验证的结果会分别说明。

## 适合做什么

- 推敲科研 idea：构造成立条件、设计方法、寻找证明或实验路径。
- 分析论文方法：理解贡献，寻找可以继续推进的机制与边界。
- 跨领域迁移：对应两边的变量和约束，检查哪些结构可以真正用上。
- LLM systems 和优化：分析资源瓶颈、算法代价和可行的改进方向。
- 代码排障与性能分析：定位问题、修改代码、运行验证。
- 改写技术文字：保留技术内容，去掉翻译腔和空话。

## 安装

下载这个仓库，把整个目录复制到 Codex 的 skills 目录，并命名为 `research-engineering-partner`：

- Windows：`%USERPROFILE%\.codex\skills\research-engineering-partner`
- macOS / Linux：`~/.codex/skills/research-engineering-partner`

保留 `SKILL.md`、`agents/` 和 `references/` 的目录结构。重新打开 Codex 会话后，可以直接指定使用 `research-engineering-partner`；符合任务时，Codex 也可以自动选用。
